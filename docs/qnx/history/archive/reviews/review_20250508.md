## 2. Impact on Existing Builds (#ifdef Leakage)

### ⚠️ Note: symbolize.h Has Potential Duplicate Include

**Problem Location (`symbolize.h` lines 63-70):**
```cpp
#if defined(__ELF__)  // defined by gcc
#if defined(__QNX__)
#include <sys/elf.h>
#elif defined(__OpenBSD__)
#include <sys/exec_elf.h>
#else
#include <elf.h>
#endif

#if !defined(ANDROID) && !defined(__QNX__)
#include <link.h>  // For ElfW() macro.
#elif defined(__QNX__)
#include <sys/elf.h>  // ← Already included above!
#endif
```

**Problem:** On QNX, `<sys/elf.h>` is included twice.
**Impact:** Normally blocked by header guards `#ifndef`, but redundant.
**Proposed Fix:**
```cpp
#if !defined(ANDROID) && !defined(__QNX__)
#include <link.h>  // For ElfW() macro.
#endif
```
