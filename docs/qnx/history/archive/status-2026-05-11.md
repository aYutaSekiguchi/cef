## Goal
Compile and link `base_unittests` on QNX SDP 8 (`x86_64-unknown-nto`).

## Important Discovery: Gap Between BUILDFLAG(IS_LINUX) and GN is_linux

```
GN:   is_linux = current_os == "linux" || is_qnx  →  true on QNX
C++:  BUILDFLAG(IS_LINUX) is determined by __linux__ definition → 0 on QNX
```

This is the root cause of many errors. GN's is_linux=true makes files build targets,
but C++'s IS_LINUX=0 prevents guards from working, causing Linux-specific code to
be compiled and error out.

**Policy**: Setting IS_LINUX=1 is dangerous (prctl FATAL crashes, etc.).
Keep IS_LINUX=0 and add IS_QNX guards to individual files.

## Key Design Decisions
- Setting BUILDFLAG(IS_LINUX) to 1 on QNX is **prohibited** (prctl FATAL crashes, etc.)
- Gap between GN is_linux=true (toolchain sharing) and C++ IS_LINUX=0 (feature guards) is **intentional design**
- Same pattern as ChromeOS/Android/Fuchsia: GN sharing + C++ exclusive flags for branching
- EPOLLONESHOT: Strip bits before passing to QNX kernel, call StopEpollEvent manually
- sys_info_qnx.cc: Get accurate memory via sysconf(_SC_PHYS_PAGES/_SC_AVPHYS_PAGES)
