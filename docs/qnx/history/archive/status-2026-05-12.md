## Goal
Progress `base_unittests` build on QNX SDP 8 (`x86_64-unknown-nto`) while keeping the configuration of **compile with bundled clang / link with QNX `qcc`**.

## Key Decisions
- **Final form maintains compile=clang / link=qcc**

- QNX shares many Linux build configs; **pruning linker flags / default libs via explicit QNX branches** is effective
- Since `BUILDFLAG(IS_LINUX)` is `true` on QNX, put `is_qnx` guards **explicitly first**
- **Rust-on-QNX is Option B** (use existing Chromium rust toolchain)
  - Move `is_qnx` branch before `is_linux` in `build/config/rust.gni`
